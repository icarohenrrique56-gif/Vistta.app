# Guia do usuário

1. Entre com e-mail/senha ou Google.
2. No primeiro acesso, informe o nome da ótica.
3. Abra o Caixa Diário antes de vender.
4. Cadastre produtos e clientes.
5. No PDV, busque produtos, monte o carrinho, selecione pagamento e finalize.
6. Use Orçamento quando a venda ainda não estiver pronta.
7. Crie ou converta uma OS para acompanhar montagem e entrega.
8. Consulte Ajuda e treinamento para os fluxos detalhados.

Para recuperar a senha, informe o e-mail na tela de login e use “Esqueci minha senha”.
