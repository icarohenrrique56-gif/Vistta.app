# Privacidade

Dados tratados incluem conta de usuário, nome/e-mail, dados da ótica, clientes, telefone, CPF/CNPJ, nascimento, endereço, receita ótica, vendas, ordens e dados financeiros inseridos pelo usuário.

Os dados são armazenados no Firebase Realtime Database e acessados por usuários autorizados da empresa conforme as regras. O sistema oferece solicitação de exclusão por e-mail, mas retenção, exportação, base legal, controlador, operador e prazos devem ser definidos pelo responsável do produto com validação jurídica.

Não há banner de cookies porque o código auditado não implementa cookies próprios. Analytics não está inicializado no frontend atual.
