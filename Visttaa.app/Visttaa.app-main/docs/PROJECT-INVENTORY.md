# Inventário do projeto

- Frontend: `src/`.
- Assets: `public/assets/logos/vistta-logo.png`.
- Firebase Web: `src/config/firebase.ts`.
- Contexto e listeners: `src/context/AppContext.tsx`.
- Regras: `database.rules.json`.
- Functions: `functions/src/index.ts`.
- Build: Vite, TypeScript, Tailwind e PostCSS.
- Sem router de URL, testes automatizados, lint configurado, Firestore ou Storage.
- Dependências frontend declaradas e usadas: React, React DOM, Firebase e Lucide React.
- Categoria de produto: ERP operacional/comercial vertical para óticas; não é ERP industrial ou fiscal completo.
- Lacunas prioritárias: auditoria de negócio, backup operacional, testes automatizados, permissões granulares, compras e movimentação formal de estoque.
