# Guia do administrador

Administradores podem gerenciar financeiro, contas, fornecedores, categorias e usuários. O convite de usuário cria uma conta Firebase, grava o perfil da empresa e envia redefinição de senha.

Revise periodicamente os usuários cadastrados e remova acessos que não sejam mais necessários. A autorização real está nas regras do Realtime Database e nas Cloud Functions; esconder itens da sidebar não é controle de segurança.
